# ZERO HOUR — The Experiential Crucible

> **"Leadership cannot be developed by observation alone. It has to be practised."**  
> *Discuss. Debate. Disrupt.*

Zero Hour is a student-led platform for leadership, public affairs, and real-world decision making. Built as an institutional crucible, it bridges the divide between theoretical discourse and high-pressure execution across diplomacy, parliamentary debate, public policy, and civil administration.

---

## 🏛️ Foundational Philosophy

```
RESEARCH → THINK → SPEAK → NEGOTIATE → DECIDE → LEAD
```

- **Research**: Forensic investigation of primary sources, statutory precedents, and intelligence whitepapers.
- **Think**: Strategic synthesis under time-compressed cognitive scrutiny.
- **Speak**: Forensic oratory and persuasive cadence under adversarial cross-examination.
- **Negotiate**: Multilateral coalition building and consensus statecraft.
- **Decide**: Decisive executive commitment under high-ambiguity conditions.
- **Lead**: Total institutional stewardship and personal accountability for outcomes.

---

## 📑 The Four Domains

1. **Diplomacy**: Model United Nations, crisis committees, bilateral negotiations, and multilateral treaties.
2. **Debate**: Oxford-style, British Parliamentary, and Asian Parliamentary forensic rhetoric.
3. **Public Policy**: Statutory drafting, macroeconomic modeling, and regulatory impact assessments.
4. **Administration**: Crisis war-room command, civil service logistics, and disaster management protocols.

---

## 💻 Tech Stack

- **Framework**: React (Vite)
- **Styling**: Tailwind CSS v4 with custom editorial design tokens
- **Motion**: Framer Motion
- **Icons**: Lucide React
- **Typography**: Google Fonts (*Newsreader*, *Plus Jakarta Sans*, *JetBrains Mono*)

## 🚀 Quick Start

### 1. Clone & Install
```bash
git clone https://github.com/PRINCE-CODER679/ZERO-HOUR.git
cd ZERO-HOUR
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open `http://localhost:5173` (or the port specified in terminal) in your browser.

### 3. Build for Production
```bash
npm run build
```
